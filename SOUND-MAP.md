# POINT NEMO — which sound plays for which event

98 events have voice clips (your 133 lines). When an event has several clips, one plays at random.
Clip numbers match the files in share/voice/ (installed to ~/.local/share/point-nemo/voice/).

## Handy commands
- nemo test <event>      play an event now (ignores mute and cooldown)
- nemo vol [pct]         show / set the Point Nemo volume
- nemo mute [min]        silence everything; nemo unmute
- nemo-demo [--fast]     the 20-scene hacker demo
